# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Before v0.1.0 | The latest commit on `main` only |
| v0.1.0 and later | The latest minor release |

Fixes land on `main` first. Once v0.1.0 is released, upgrade to the latest
minor release to receive them.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Fill in the advisory form.

Direct link:
<https://github.com/RabbITCybErSeC/simple-siem/security/advisories/new>

Do not open a public issue for a vulnerability. A public issue tells everyone
about the problem before a fix exists.

Please include:

- the version from `simple-siem version`;
- the steps to reproduce the problem;
- the impact you expect, and any conditions it needs, such as configuration,
  permissions, or data.

## What to expect

- We acknowledge your report within 7 days.
- We keep you updated as the fix progresses.
- We coordinate disclosure with you before we publish an advisory.
- We credit you in the advisory if you want credit.
